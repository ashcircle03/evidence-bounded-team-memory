# Fixed-span pair assignment v1

Scope: existing records spans, same Qwen3-8B, no training, gold/scorer changes,
new model or post-hoc semantic validator. No prompt examples from this benchmark.

Two concrete implementation differences from the references:
1. Graphiti receives both existing endpoints and typed relations. Our earlier
   target-only prompt freely generated the other endpoint while assigning it.
2. GLiNER/PAIE identify a concrete instance/anchor. Our adapter converted that
   anchor to claim_group; v3 storage and readers then broadcast the context to
   every assertion in the group. Identity resolution must not broaden scope.

Build source-grounded endpoint catalogs from the unchanged original Qwen raw
extractions. Every role supplies a possible context, including an old claim
that may actually be a rationale. Targets are individual original claim spans.
Do not add ground-truth spans. Do not retokenize a new quote generated by Qwen.
Use the previously tested no-complete-target containment endpoint constraint.
Baseline failed documents remain failed, with no new inference: this is counted
as unavailable input, not a correct negative or a solved extraction.

For one fixed context at a time, classify its relation to each eligible target:
none / condition / basis. All targets require a label; multiple positive targets
are legal only if supported separately. Full source and original metadata are
available; existing role assignments are not supplied as answers. Temperature0,
seed42, thinking off, max256 generated tokens per context, concurrency4. Original
extraction is cached and unchanged. Cost reflects the increased number of calls.

Persist new bindings as explicit assertion-span/context-span edges in v4, retaining
the exact old v3 units, claims, assertions, stances and legacy edges. No duplication
of stored assertions or transfer of state authority. A 'none' prediction deletes
nothing. Records append/restart/read and reader context must preserve exact target
identity. Structural failures are explicit; there is no semantic fallback.

The fixed scorer accepts groups rather than directed edges. A new representation
adapter renders each v4 edge as a target/context view for scoring; the original
v3 views are unchanged. This does not create duplicate stored assertions. Verify
old scores exactly and report unchanged physical assertion counts separately.

Controls: baseline; pair classification with v4 atomic persistence; the same new
predictions collapsed back to v3 group persistence. The latter is an ablation of
the old integration bug, not a selectable per-document fallback. Also report
earlier8B candidate metrics without claiming identical cost/candidate availability.

Acceptance unchanged: no lost previously correct content, links, stances or fully
correct documents; no extra false links or extra rows in either panel; at least
one new correct condition/basis edge. Do not tune thresholds or select per-case
outputs after evaluation. Same68 documents and fixed difficulty/availability.
Natural14 are known failure audits, not an independent generalization benchmark.
