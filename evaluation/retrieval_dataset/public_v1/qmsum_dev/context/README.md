# QMSum 개발셋에서 앞뒤 발화를 이용한 재정렬

35개 회의의 235문항 전부에서 이전 실험의 RRF 후보와 상위 5개 발화 ID를 고정했다. 사전 지정한 주 비교는 앞·뒤 한 발화를 함께 읽는 cross-encoder와 기존 RRF 및 중앙 발화만 읽는 동일 cross-encoder의 차이다. 앞만 또는 뒤만 읽는 설정은 방향별 진단이다. 파라미터 학습, 후보 검색 재실행 및 test 분할 사용은 없었다.

- 질문과 문서의 쌍을 같은 MS MARCO MiniLM-L6 모델로 점수화했다. 문서는 이전 발화, 중앙 발화, 다음 발화 순이며 구간을 BERT의 SEP 토큰으로 분리한다. 각 발화에 화자 이름을 포함한다. 회의 경계에는 이웃을 추가하지 않는다.
- 최대 512토큰에서 질문과 중앙 발화의 기존 토큰을 먼저 보존한다. 남은 공간에 이전 발화의 끝과 다음 발화의 시작을 나누어 담는다. 문맥 창은 점수를 매길 때만 사용한다. 반환 단위와 정답 판정 단위는 원래 중앙 발화다.
- 모든 문항에서 상위 5개 집합과 6위 이후 순서가 RRF와 일치하는지 검사했다. 중앙 발화 단독 방식은 기존 cross_top5의 전체 순위를 문항별로 재현했다. Hit@1과 범위 Recall@5는 문항별 평균이다. 차이의 95% 구간은 같은 35개 회의를 양쪽에 함께 재표집한 percentile 구간이다(10,000회, seed 20261122). MRR@5에서는 5위까지 적중이 없으면 0점이다.
- 85개 진단 문항은 변경 전 RRF에서 1위가 틀렸으나 후보 안에 관련 발화가 하나 이상 있는 문항이다. 이 부분집합에서 획득 건수를 구하고, 전체 비교에서는 기존 1위 정답 100문항에서 생기는 손실까지 포함한다. 나머지 50문항은 전체 후보에 주석 발화가 없다.

## 개발셋 결과

| 재정렬 입력 | Hit@1 | RRF 대비 획득 / 손실 | Hit@1 차이, %p (95% CI) | 범위 Recall@5 | MRR@5 |
|---|---:|---:|---:|---:|---:|
| RRF | 100/235 (42.55%) | — | — | 72.98% | 0.5397 |
| 중앙 발화 | 98/235 (41.70%) | 28 / 30 | −0.85 [−6.05, +4.17] | 72.98% | 0.5423 |
| 이전 + 중앙 | 111/235 (47.23%) | 36 / 25 | +4.68 [−0.92, +9.64] | 72.98% | 0.5674 |
| 중앙 + 다음 | 102/235 (43.40%) | 28 / 26 | +0.85 [−4.89, +6.32] | 72.98% | 0.5562 |
| 이전 + 중앙 + 다음 | 107/235 (45.53%) | 31 / 24 | +2.98 [−2.21, +7.75] | 72.98% | 0.5601 |

앞뒤를 함께 읽으면 중앙 단독 대비 19문항을 얻고 10문항을 잃었다(+3.83%p, 95% CI [0.00, +7.49]). 이전 발화만 추가하면 19문항을 얻고 6문항을 잃었다(+5.53%p, [+1.72, +9.35]). 다음 발화만 추가한 차이는 +1.70%p [−1.76, +5.42]였다. 상위 5개의 ID가 고정되어 모든 문항에서 범위 Recall@5 차이는 정확히 0이었다. 개발셋에서는 이전 발화만 추가한 설정이 가장 유망하지만, RRF 대비 Hit@1 차이의 구간에는 0이 포함된다. 방향별 탐색 결과는 독립 평가로 확인해야 한다.

상위 5개 안에서 복구 가능한 74문항 중 앞뒤 문맥은 31문항을, 이전 문맥은 36문항을 복구했다. 이전 문맥에서 복구된 36건 중 28건은 원래 첫 정답이 2~3위였다. 앞뒤 문맥을 넣고도 복구하지 못한 43문항에서 최종 1위의 바로 옆 발화가 정답인 사례는 2건이었다. 나머지 11문항은 첫 정답이 6~8위여서 이번 재정렬 범위로는 1위에 올릴 수 없다.

## 재현

public_v1 디렉터리에서 기존 dev 실험 환경으로 실행한다. RAW는 고정된 공식 ALL/val.jsonl을 meetings.jsonl로 저장한 경로, CROSS_ENCODER는 이전 실험과 동일한 모델 디렉터리다.

```sh
python dev_context.py --dev qmsum_dev --raw "$RAW" --encoder "$CROSS_ENCODER"
python dev_context_score.py qmsum_dev
```
