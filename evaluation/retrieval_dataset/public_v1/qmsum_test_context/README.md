# F05 문맥 재정렬의 QMSum 테스트 결과

개발셋에서 정한 두 입력 방식을 QMSum 공식 테스트 회의 중 동결된 F05 평가셋(35개 회의, 범위 주석이 유효한 242문항)에 적용했다. 기존 팀 RRF 테스트 결과는 이전 BM25 비교에서도 사용했다. 이번 두 설정의 선택에는 개발셋을 사용했다.

| 입력 | Hit@1 | RRF 대비 차이, %p (95% CI) | MRR@5 | RRF 대비 차이 (95% CI) | 범위 Recall@5 |
|---|---:|---:|---:|---:|---:|
| 기존 RRF | 99/242 (40.91%) | 기준 | 0.5702 | 기준 | 76.79% |
| 이전 + 중앙 | 127/242 (52.48%) | +11.57 [+5.02, +18.01] | 0.6366 | +0.0665 [+0.0280, +0.1035] | 76.79% |
| 이전 + 중앙 + 다음 | 124/242 (51.24%) | +10.33 [+4.56, +16.22] | 0.6242 | +0.0541 [+0.0178, +0.0910] | 76.79% |

각 문항에서 기존 team-predictions.jsonl의 상위 5개 자리를 그대로 사용했다. 한 문항의 중복 발화도 그대로 두었다. 동일한 개발셋 모델과 입력 구성으로 발화 순서만 변경했다. 중앙 발화가 주석 범위 안에 있으면 적중이다. Recall@5는 문항별 정답 범위 중 상위 5개 발화가 적중한 범위의 비율을 평균한다. 후보와 중복 횟수가 보존되어 두 설정 모두 문항별 Recall@5 차이가 0이고, 평균 차이의 95% 구간도 [0, 0]%p다.

이전 + 중앙은 기존 1위 오답 중 45건을 복구하고 기존 적중 중 17건을 잃었다. 앞뒤 모두 사용하면 45건을 복구하고 20건을 잃었다. 구간은 같은 회의를 짝지어 재표집한 백분위 부트스트랩(35개 회의, 10,000회, seed 20261122)으로 계산한 개별 95% 구간이다. 두 문맥 설정 사이의 우열은 표의 RRF 대비 구간으로 판정할 수 없다.
