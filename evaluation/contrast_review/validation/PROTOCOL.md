# 독립 후속 검증

첫 여섯 보고에서 비참조 방식이 모든 양성을 보류했다. 이를 본 후 명시적인 회귀 귀속이 있는 경우만 별도 처리하는 후보를 만들었다. 두 번째 평가의 다섯 보고는 첫 평가나 이전 프로젝트 평가에 쓰지 않은 Git 사례다. 회귀를 지목한 표현 바로 뒤의 ID가 과거 출처의 실제 ID와 유일하게 맞는지 먼저 검사한다. 관측·조건에 대한 별도 원문과 대안 구절을 골라 Qwen이 설명한다. 참조된 결정이 후보에 없으면 보류하고, 인식 가능한 방향성 있는 귀속 표현이 없으면 첫 대비 방식으로 판단한다. 전체 SHA나 제목 일치만으로 설명 점수를 주지 않는다.

같은 보고로 양성 후보와 비슷한 과거 결정이 있는 조건, 비슷한 과거 결정만 두 개 있는 조건, 비슷한 결정 하나뿐인 조건을 만든다. SHA와 앞선 기록 제목을 가린 보조 실험도 양쪽에 적용한다. 이전 사전 채점 기준과 적중·구별·오탐 기준을 그대로 쓴다. 두 차수의 표본은 따로 보고한다. 마스킹되는 참조 표현은 원래 모델 입력에 실제로 있었다. 최종 방식의 명시적 참조 효과를 일반 의미 이해 성과로 해석하지 않는다. 같은 20개 기존 QA의 정답·인용을 다시 재현하고 검토함을 쓰는 Git pull에서도 독립적으로 확인한다.
