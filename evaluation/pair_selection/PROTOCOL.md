# Candidate-local review selection

Compare the frozen joint Qwen constrained reader (raw-only A) with independent assessment of each raw past source against the arriving report. First score the compatibility of the whole decision and update, then score whether individual paragraph pairs alone justify a change. Use the smaller of the two Yes-minus-No logits, stable provenance ties, and request review only above zero. Generate the reason from only the selected paragraphs. Candidate-local model inputs contain the supplied goal and raw text only. They do not contain options identifying which document should win. Up to five body passages per side per source. Both arms can access the same original documents. Report different actual compute costs.

Run both candidate orders on every case independently on the GPU and compare canonical source location and paragraph, using the frozen key on positive cases. Three separate measures are stability, correct prior decision/topic, and both cited paragraphs meeting the key. A grounded review further requires the review action and a specific, supported explanation matching the case rubric. Neither repeated abstention nor a source title without the required information earns a hit. A keep requires no review; report false alerts and invalid separately. Inspect reasons with method/order masked. Threshold for adopting the review method: more grounded positive hits and no extra false positives on new Git cases, consistent action/target/both actual paragraphs on reversal. Distinguish previously seen Git, controlled changed conditions, Aimers, and four unseen positive plus four negative historical Git reports. A single repository and selected pairs cannot establish general performance.

QA is a separate read path. Test the 16 historical ordinary and 4 multisource gold successes on the original successful configurations, and inspect the existing same-reader same-inbox QAs separately. Compare actual answers and citation identity, allowing harmless formatting variations; new correct answers cannot offset a lost answer or citation. Exercise normal store review context on a pending proposal and ensure it does not replace QA evidence. A cross-configuration historical success suite is a regression measure, not one reader's accuracy. Do not alter QA or tune on the final cases. Staged Qwen jobs on Aurora, one GPU at a time with 15 minute reservations within the existing 120 GPU-minute campaign.
