# 사전 판정 기준

개발 사례는 과거 checkout이다. 알고리즘·영점 임곗값과 채점표를 고정한 뒤 새 Git 결정 6개에 실제 회귀 6건과 주제는 겹치지만 과거 결정을 재검토할 이유가 없는 실제 변경 6건을 짝지어 검사한다. 6개의 회귀 보고를 이웃한 다른 결정에 붙인 검사도 분리한다. 이 교차 검사는 보조 음성으로만 사용한다.

고정 실험에서는 양성의 근거 문단 두 개 또는 음성의 비교할 관련 원문 문단 두 개를 제공한다. 기본 비교기는 직전 pairwise의 문서 및 해당 문단 점수를 사용한다. 두 필드의 시점 표지는 유지하고 표시 위치를 뒤집어 두 점수의 부호와 최종 행동을 기록한다. 결정과 별개로 모든 고정 문단에 설명 생성을 강제해 실제 제안과 따로 채점한다. 수정안은 재검토와 독립 변경이라는 가설을 두 표시 순서에서 채점해 차이의 평균을 0과 비교한다. 설명 입력은 시점 순서로 정규화하고 바뀐 조건을 담은 문장 하나를 먼저 선택한다. 양 방향 점수를 결합한 결과의 순서 불변성과 모델 자체 판단이 순서에 둔감하다는 주장을 구별한다.

실사용 평가에서는 두 방식 모두 주어진 과거 원문 전체(대상과 대안)와 새 보고에서 출발하며, 같은 기존 선택기를 사용한다. 고정 문단 위치나 정답은 검색과 판정에 전달하지 않는다. 근거 있는 재검토는 제안을 실제 발행하고, 양측 인용이 사전 지정 문단에 해당하며, 원문에 근거해 무엇이 어느 조건에서 달라졌는지 설명한 경우다. 관련 주제 언급, 원문을 단순 나열한 답, 잘못 확장한 조건은 실패다. 출력 형식을 가린 설명 카드를 섞어 1인이 판정한다. 실제 Git 회귀의 근거 있는 적중이 이전 방식보다 늘고 음성 6건의 오탐이 0이며 기존 정답과 출처 손실이 없어야 기본값 승격을 검토한다. 고정 근거 조건의 성공만으로 승격하지 않는다.

QA는 원래 성공한 일반 16문항·다중 근거 4문항의 당시 배치와 채점기를 복원하고 추가로 현재 Git pull을 거친 복제본과 같은 기록의 대조 복제본에서 답과 출처를 대조한다. 같은 Qwen2.5-3B-Instruct 가중치·BF16·greedy·출력 한도를 사용한다. 조건 분리 진단과 실패까지 기존 Aurora 120 GPU분 캠페인 상한에서 집행한다.
