# 독립 검토자용 입력

검토자는 이 폴더의 events.json과 inputs.json.gz만 열고, key.json과 결과 보고서는 응답을 제출한 뒤 열어 주세요. 정답과 시스템 출력을 받지 않고 독립적으로 작성할 수 있도록 입력 아카이브에는 두 가지 모두 포함하지 않았습니다. inputs.json.gz는 UTF-8 JSON입니다. 각 항목에서 history는 당시 검색 가능했던 문서, incoming은 새 문서입니다. source.location의 커밋 링크를 이용하면 원문을 대조할 수 있습니다. 소급해서 편집된 현재 PEP 페이지나 이후의 결의는 이 검토에 쓰지 않습니다.

각 목표마다 아래 한 줄을 작성합니다. 대상이 없거나 복수일 때는 그 점을 기록합니다.

| 사건·목표 | 관련된 과거 PEP와 정확한 구절 | 허용 조치(복수 가능) | 새 기록에서 달라진 조건과 근거 구절 | 피해야 할 조치·이유 |
|---|---|---|---|---|
| annotations / implementation | | | | |
| threading / support | | | | |
| threading / default | | | | |
| imports / opt_in | | | | |
| imports / ordinary | | | | |

각 사건의 historic 및 new 질문에 대해 당시 가능했던 답, 답을 지지하는 PEP 번호·구절, 추가 설명이 필요한 점을 적습니다. 유지·비교 제안·제약 유지·기존 작업에 연결·근거 추가 요청이 모두 부적절하면 자유서술로 남깁니다. 두 검토자의 독립 응답을 먼저 보존하고 대상과 허용 조치의 겹침 및 이견을 사건별로 기록한 뒤 합의합니다.
