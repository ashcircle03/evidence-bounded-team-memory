# v0.2.1 records와 원문 QA의 MeeQA 비교

MeeQA 공식 original 검증 분할을 고정 리비전 7b9a6c43eef4e0830336862ffc19b48ff52615a6에서 가져왔다. 질문은 참가자가 실제 회의에서 한 질문이다. 배포본의 answers.text 및 answer_start는 주석자가 고른 답 구절과 문자 위치이고, is_impossible은 해당 발언 창에서 답할 수 있는지 표시한다. 따라서 이 데이터는 답과 인용·보류를 비교할 수 있다. 발언 사이의 필수 조건·이유 연결이나 사람이 정리한 records까지 주어진 것은 아니다. [원 논문](https://arxiv.org/abs/2305.08502) · [공식 검증 파일](https://github.com/reutapel/MeeQA/tree/7b9a6c43eef4e0830336862ffc19b48ff52615a6/Data/original)

- 같은 질문에 응답한 서로 다른 주석자가 둘 이상이며 답 유무가 일치하는 경우 중 명료성·관련성·자기완결성이 모두 참이고 원문 위치가 일치하는 행을 사용했다. 고정 해시 순서로 회의를 중복하지 않고 답 가능 4개·불가능 4개를 선택했다. 기존 68개는 사용하지 않았다.
- 질문별로 제공된 원래 발언 창 전체를 두 arm에 동일하게 제공한다. 화자 표기는 창 내부의 익명 ID다. 자료 창은 이미 질문에 맞춰 만들어져 있어 전체 회의 검색이나 시간에 따른 상태 승인 성능까지 측정하지 않는다. 각 원래 발언은 하나의 source가 된다. 질문·사람 정답·근거 구절을 추출기에 전달하지 않는다. 날짜는 null이다.
- 동일 Qwen3-8B 리비전, 온도 0, seed 42, reader 프롬프트·512 출력토큰을 사용한다. records arm에는 v0.2.1 주장 그룹, 역할 및 원문 위치를 더한다. GUM 역할 헤드는 체크포인트 124235를 사용한다. 선택된 434개 발언 중 정책 구문 보정이 요구하는 두 필수 어휘 조건을 모두 충족한 발언은 없다. 입력별로 이를 검사한다. records는 문서별로 질문에 관계없이 만든다. vLLM에는 정답·보류 라벨을 올리지 않았다.
- 답변은 extractive token F1과 정규화 완전 일치, 인용은 실제 원문과 일치하는 유일한 구절의 위치 완전 일치와 문자 구간 F1, 보류는 답 불가 4건의 올바른 보류와 답 가능 4건의 잘못된 보류를 따로 본다. 한 주석자의 복수 구절은 하나의 정답 집합으로 유지하고 다른 주석자의 정답 집합은 대안으로 인정한다. 단일 연속 인용을 요구하므로 불연속 근거는 한 번에 완전히 표현하기 어렵다. 세부 의미 차이는 원출력·원문 대조로 확인한다.
- 4개 답 가능 질문 중 3개에서 제공된 구절의 범위가 주석자 사이에 달랐다. 이는 사람 답 유무 합의와 정확한 인용 경계 합의가 다른 지표임을 보여준다. 사람 정답을 그대로 넣는 검사에서 답·근거 4/4와 보류 4/4, 항상 보류 검사에서는 답 가능 문항 0/4와 보류 4/4를 확인했다. 이 검사 수치는 모델 예측 결과가 아니다.

고정 입력과 주석 키의 해시는 manifest.json에 기록했다. Aurora 작업 124280은 모델 로드 후 NLTK가 공유 캐시를 거부하여 첫 답 생성 전에 종료됐다(client exit 1). 복구 작업 124297은 같은 aurora-g1의 기존 입력 파일과 같은 모델·프롬프트·채점 기준을 사용한다. 변경 사항은 영어 문장 분할 자료와 stopwords를 해시 검증 후 작업 전용 경로에서 읽는 것이다. 문항 선택·입력 구성·채점 코드는 evaluation/meeqa_pilot에 있다.

## 실행 결과

124297은 aurora-g1에서 GPU 1개로 9분 41초 실행해 COMPLETED, ExitCode 0:0으로 종료됐다. 프로그램 완료, 고정 입력 SHA-256, 434개 발언과 16개 응답을 확인했다. 원문과 원문+records 순서로 답 불가 문항의 올바른 보류는 0/4와 3/4, 답 가능 문항의 잘못된 보류는 각각 2/4다. 답 가능 문항의 정규화 완전 일치와 인용 위치 완전 일치는 양쪽 모두 0/4다. reader 입력은 각각 합계 15,894토큰과 56,899토큰이다. writer 비용은 별도다.

회의록의 수정안 채택 발의와 25유로 제품의 구매 대상에 관한 핵심 발언은 records에도 전달됐다. 두 조건 모두 해당 문항에서 보류했다. 이 표본에서 먼저 점검할 부분은 reader가 간접적·조건부 답을 인정하는 기준과 실제 인용 위치 선택이다. 추출 그래프 23/434건은 failed였고, 패션에 민감한 구매자를 예로 든 후속 발언도 주장이 비어 있었다. 근거 보존과 그 근거를 사용한 최종 답변은 분리해서 평가한다.
