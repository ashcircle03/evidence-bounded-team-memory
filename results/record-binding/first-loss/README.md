# records의 첫 수정 대상은 추출된 구절의 역할 판정이다

원문에서 이미 뽑아 둔 두 구절의 연결을 보존하면서 조건·이유 역할을 판정하는 부분부터 다룬다. 오래된 그룹에서 주장이 하나로 정해지는 사례를 첫 적용 범위로 삼는다. 자연 기록 n03과 n08에서 이 수정만으로 기존 정답 손실 없이 누락 연결을 복구할 여지가 확인됐다. 같은 그룹에 여러 주장이 있는 n12와 n13에서는 역할을 고치면 기존 평가에서 맞지만, 저장된 그룹만으로 개별 대상을 증명할 수 없다.

## 어느 단계에서 틀어졌나

합성 54문서와 이미 실패를 조사한 자연 기록 14문서에서 모든 필수 관계 129개를 추적했다. 기존 records는 44개를 맞히고 85개를 놓쳤다. 조건·이유는 전체 필수 관계 중 67개다. 고정 평가의 필수·선택 연결, 원출력, 원문 문자 위치, 저장된 그룹, 저장소 재시작 후 reader가 받은 원문과 역할 구절을 대조했다. 192개 그룹의 저장된 역할 구절이 reader 입력에 그대로 도달했다. 이 경로는 해당 기록을 지정해 읽는 실험이다. 검색 성공률이나 최종 QA까지 측정하지는 않는다.

- 기존 오연결 26개는 20문서에 분포했다. 26개 모두 해당 그룹의 기존 Qwen 원출력을 같은 기준으로 채점했을 때 대응하는 오류가 있었다. 채점 결과를 한 원인에 우선 배정하면 잘못된 역할 13개, 정답 대상과 연결할 수 없는 그룹 8개, 완전한 정답 구절과 매칭되지 않은 근거 3개, 다른 대상 2개다. 단위는 채점된 관계이며, 원문 의미가 모호하거나 복수 주장이 있는 그룹은 원출력 행과 그룹을 그대로 남겼다.
- 저장이 실패한 7문서에서 원출력 기준으로 이미 맞았던 필수 연결 11개가 사라졌다. 이 11개는 5문서(합성 3, 자연 2)에 모였다. 예를 들어 n07의 필수 조건·이유 4개 중 저장 이전에 이미 맞았던 것은 1개다. 전체 문서를 저장하지 못했다는 이유로 나머지 3개까지 저장 단계의 손실로 세면 수리 효과를 과대평가한다.
- 기각된 연결기의 1,192개 대상–근거 판단도 원문 위치와 역할로 기록했다. 320개 양성 판단과 고정 평가기의 오연결 380개는 단위가 다르다. 정답이 기록되지 않은 양성을 일괄 음성 처리하지 않았다. 세부 분류는 같은 위치와 정답 토큰이 일치하는지에 기반하며, 모든 가능한 쌍을 사람이 다시 주석한 결과가 아니다.

## 한 요소만 정답으로 바꾼 비교

표의 단위는 서로 다른 문서 수 / 필수 연결 수다. 이미 기존 records가 맞힌 연결은 복구 건수에서 제외했다. 역할 교정은 기존 행 하나의 역할만, 대상 교정은 기존 행 하나의 그룹만 바꿔 고정 채점기로 다시 계산했다. 기존 정답 내용·연결·stance 손실이나 새 오연결을 일으킨 교정은 복구 집계에서 제외했다. 각 시도는 원래 출력에서 출발했다.

| 기존 records에서 바꾼 부분 | 합성 문서 / 연결 | 자연 문서 / 연결 |
|---|---:|---:|
| 같은 구절과 같은 그룹에서 역할만 교정 | 8 / 10 | 4 / 4 |
| 기존 역할과 구절을 보존하고 대상 그룹만 교정 | 3 / 3 | 0 / 0 |

자연 기록에서 역할 교정으로 복구한 4건은 저장 수요를 비교 실험의 이유로 읽는 n03, 잠긴 계정을 정책 적용 조건으로 읽는 n08, 차트 표시를 데이터 통합의 목적으로 읽는 n12, 서비스 안정화를 업그레이드의 조건으로 읽는 n13이다. 앞의 두 건은 복수 주장 소유권 문제 없이 검증할 수 있다. 뒤의 두 건은 그룹 기준의 복구다. 역할 교정이 조건·이유 전체를 해결한다는 추정에는 근거가 없다.

이전 고정 구절 연결기의 실험은 별도로 봤다. 자연 13개 필수 조건·이유 중 5개가 실제로 선택 가능했고 그중 2개에서 올바른 역할을 출력했다. 합성은 54개 중 38개가 선택 가능했고 그중 21개를 맞혔다. 다음 표에서 구절 교정은 선택 가능성만 세고, 역할·대상 교정은 실제로 출력된 양성 라벨을 이용한다.

| 고정 구절 연결기의 입력 또는 출력을 한 곳만 교정 | 합성 문서 / 연결 | 자연 문서 / 연결 | 의미 |
|---|---:|---:|---|
| 정답 근거 구절 제공, 기존 대상 고정 | 7 / 7 | 3 / 3 | 추가 선택 가능 |
| 정답 대상 구절 제공, 기존 근거 고정 | 1 / 1 | 1 / 1 | 추가 선택 가능 |
| 실제 양성의 역할을 유지하고 대상만 정답 위치로 이동 | 6 / 8 | 2 / 2 | 개별 연결 복구 상한 |
| 정확한 쌍에서 실제 양성의 역할만 교정 | 8 / 10 | 2 / 2 | 개별 연결 복구 상한 |

첫 두 행은 새 쌍에 대한 모델 판단을 추정하지 않는다. 대상 교정은 같은 근거에서 틀린 대상으로 보낸 양성을 옮길 수 있을 때만, 역할 교정은 양성으로 판단한 기존 쌍의 종류만 잘못됐을 때만 센다. NONE을 바꿔 관계를 새로 만드는 경우는 제외했다. 사례별 상한은 합산할 수 없다. 저장 실패 문서에는 임의의 추출 후보를 주입하지 않았다.

## 우선순위와 레퍼런스 적용

기존 구현의 역할 교정이 자연 4문서, 대상 교정이 0문서에서 연결을 복구했다. 구절 분리가 추가로 가능하게 만드는 자연 3문서는 후속 판단 결과가 없는 입력 개선 기회다. 한 자연 문서를 제외해도 기존 그룹 기준 역할 교정은 3건 이상 남는다. 다만 구절 분리의 3건과 비교하면 한 문서의 차이고, 개별 소유권까지 보장되는 역할 교정은 2문서다. 이 순위는 개발 우선순위이며 새 자연 기록에서 보장되는 성능이 아니다. 합성에서는 역할 교정이 easy·medium·hard의 full·partial 모두에서 재현됐다. 표본은 난도·가용성 조합마다 6문서다. [9개 층별 결과](strata.md)

선정한 레퍼런스는 **DisCoDisCo의 combined sequence 관계 분류 구현**이다. 두 담화 단위의 원문 범위와 주변 문장, 방향 표현을 사용하고 실제 관계 라벨로 교차 엔트로피를 학습한다. 이미 짝지어진 단위의 역할을 판정한다는 점이 이번 수정 대상에 맞는다. [고정 버전의 모델 구현](https://github.com/gucorpling/DisCoDisCo/blob/66b8c4e86543f0a14913f4b57f454be80e3bfba5/gucorpling_models/rel/combined_sequence_model.py#L197) · [원 논문](https://aclanthology.org/2021.disrpt-1.6/)

우리 입력에서는 같은 그룹에서 대상 주장을 하나로 특정할 수 있는 경우에만 두 구절과 문장 문맥을 넘긴다. 원래 순서와 함께 어느 쪽이 주장이고 어느 쪽이 근거 후보인지 표시한다. n08처럼 조건이 주장 안에 포함되면 원문의 두 offset을 각각 보존한다. 담화 라벨은 원문이 명시한 적용 범위와 이유·목적에만 매핑하고, 기존 subject·시간·독립 주장과 역할을 판정할 수 없는 경우도 허용해야 한다. 공개 구현의 관계 라벨 중 하나를 항상 고르는 동작을 그대로 서비스에 적용하면 이런 기록을 오변경할 수 있다.

다음 개발에서는 한 요소씩 바꾼 진단에 사용한 gold를 추론 입력으로 넘기지 않는다. 채택은 기존 68문서의 내용·연결·stance·완전 정답 문서 보존, 양 패널 각각 오연결·불필요 추출 비증가, 새 조건·이유 정답 증가로 판정한다. 성능 일반화는 별도 자연 문서에서 확인해야 한다. 이번 결과는 새 모델 학습이나 추론으로 얻은 개선값이 아니다.

재생은 저장소 루트에서 아래 두 명령으로 가능하다. 첫 명령은 기존 동결 파일의 해시와 68개 회귀 점수가 모두 같은지 검사하고, 임시 저장소에서 reader 입력을 재구성한다.
