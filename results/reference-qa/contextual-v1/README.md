# 검색 피드백·원문 맥락 보존 결과

2026-11-07. 부분적인 복구는 있었으나 기존 QA를 대체할 기준은 통과하지 못했다. Ever10의 필수 답·근거는 이전 `claims`1/10에서 결합 후보2/10으로 늘었지만, 이전 단순 `joint`도2/10이었고 성공 문항 하나를 잃었다. 새 후보의 기존20문항은17/20이다. 선택 경로는 `attributed`를 유지한다.

## 적용한 레퍼런스

[LlamaIndex QueryFusionRetriever](https://developers.llamaindex.ai/python/framework/integrations/retrievers/reciprocal_rerank_fusion/)의 질의 생성과 reciprocal rank fusion 구현을 직접 사용했다. 첫 BM25 top8 원문에서 확인한 이름·사건으로 후속 질의3개를 만들고, 실제 작성자·기록 시각이 포함된 검색 키에서 다시 top8을 찾는다. 찾은 근거를 다음 검색에 활용하는 목적은 [IRCoT](https://aclanthology.org/2023.acl-long.557/)에서 가져왔지만, 원 논문의 전체 반복 추론이나 성능을 재현한 것은 아니다.

[Attribute First](https://aclanthology.org/2024.acl-long.182/)의 fusion-in-context에 맞춰 선택 구절이 들어 있는 검색 문단을 최종 생성기에 함께 제공했다. 기존 LangChain QuotedAnswer 스키마와 원문 위치 복원으로 각 답에 근거를 연결한다. 인용을 좁히면서 지시 대상이 빠지는 문제를 줄이려는 변경이다. 작성자·시각 필드는 이전 후보에도 전달됐으며, 이번 변경이 없던 메타데이터를 새로 만들어 낸 것은 아니다. [설계 의도·적용 범위](../../../docs/reference-contextual.md)

## 검색 회수율과 필요한 근거의 충족은 달랐다

네이티브 R 메시지 위치 회수는22/290에서30/290으로 늘었다. 그러나 필요한 사건·조건을 모두 찾았는지 원문으로 검토하면 충분4개·부분4개·부재2개로 이전과 같다. 담당자 문항은 간접적인 완료 보고에 더해 명시적인 배정 알림을 얻었지만, 나머지 기간·예외 질문의 핵심 누락은 남았다. R은 주변 맥락도 포함하므로 회수 메시지 수 증가를 정답 가능한 문항 증가로 해석하지 않는다. [위치별 전후 집계](retrieval-metrics.json) · [새 top8과 충분성 판정](retrieval-audit.json)

실제 후속 질의에서도 원인이 보인다. Zixuan Qin의 다음 업무를 찾아야 하는 질문에 Yanjun Fan과 Hongxin Ding의 업무를 검색했다. Guoxin Pan의 다음 업무 질문도 다른 사람에게 질의가 분산됐다. 정책 질문은 처음 찾은 일반 회귀 테스트나 기존 응답 규칙을 재검색했다. 첫 검색 결과에 의존하는 질의 확장이 초기 누락과 잘못된 인물 연결을 이어받았다. [실제 질의 생성 요청·응답](calls.jsonl)

구절 선택의 문제도 별도로 남았다. F_TP_Top02_048에서는1위 원문의1월20일 완료를 선택하지 않았다. F_TP_Top01_002는 날짜를 추론할 입력이 있는데도 기권했다. 메타데이터를 전달했다는 사실만으로 모델이 이를 올바르게 사용하는 것은 아니었다.

## 기존20문항 보존

새 contextual 독해는17/20이다. `PYTHONBREAKPOINT=0`과10영업일처럼 복구한 답이 있으나 다음3개를 놓쳐 기존 선택 경로의20/20을 보존하지 못했다.

| 사례 | 실패 |
|---|---|
| legacy-1d2a1e3271adf133/qa-0 | `NAME := expr`만 남기고 상대 기록의 `NAME <- expr`를 누락했다. |
| legacy-c000762632771ec9/qa-0 | `LengthMismatchError`만 남기고 PEP의 `ValueError`를 누락했다. |
| legacy-34429cce545ccddd/qa-2 | 작성자 Lizhen Zhou 대신 수신자 Luhao Zhao를 답했다. |

기존 선택 경로 `attributed`는 수정하지 않았고 저장된 초안20개·후속112개 응답을 재생해 답과 근거20/20을 보존했다. 이는 새 검색까지 포함한 재추론이 아니다. 새 후보의20문항 역시 동일한 과거 검색 입력에서 독해를 비교했으므로 전체 검색 회귀 검증으로 확장 해석하지 않는다. [기존 경로 재생 기록](attributed-replay.log)

## 형식 오류를 독해 실패와 구분한다

새50개 출력 중7개는 선택 결과가 JSON만 반환한다는 계약을 지키지 못했다. 모든 실제 응답의 종료 사유는 `stop`이므로 출력 토큰 제한으로 잘린 경우는 아니다. 특히 회계 매핑 문항은 원출력에 올바른 C와 근거가 있고 JSON도 뒤에 있지만, 앞의 정답·설명 때문에 기존 엄격 파서가 거절했다. 이를 모델이 근거를 찾지 못한 실패로 집계하지 않는다. 최종 API 답이 없으므로 일차 QA 성적에는 실패로 남긴다.

선택 프롬프트는 구절만 고르도록 지시하지만 질문 끝에는 선택지 문자로 답하라는 지시가 있다. 이번 새 검색 입력에서는 모델이 후자를 따르는 현상이 나타났다. 기존20의 상충 누락·작성자 오류와 기간 연결 실패는 별도의 의미 문제다. 형식 실패7개를 복구해도 그 의미 문제가 해결됐다는 뜻은 아니다. 원출력 확인 후 이번 고정 비교의 프롬프트나 판정을 유리하게 바꾸지 않았다.

## 실행·검증·비용

- 120274는 HTTP 요청의 `trace` 예약 필드에 로그 객체를 넣은 구현 오류로 실패했다. 실제 모델 응답 전 실패했으며10.33 GPU분을 사용했다. [실패 로그](failed-120274.log)와 첫 source 버전을 보존했다.
- 기존 코드에서 쓰던 `reference_trace` 필드로 고친 뒤 실제 로컬 HTTP 전송 검사를 통과했다. 질문·모델·검색·독해 코드는 그대로 유지하고 별도 버전120275를 제출했다. [첫 동결](initial-freeze.json) · [재실행 동결](freeze.json)
- 120275는 Slurm `COMPLETED/0:0`, 프로그램 `complete`다. GPU1개·conda 환경에서19분59초를 사용했다. 실패·준비를 포함한 이번 총비용은30.32 GPU분이다. 기존150/520/820 GPU분 상한을 유지했다.
- 실제 요청103회 중 검색 질의 생성10회, 독해93회다. 입력159,983토큰·출력19,562토큰, 외부 유료 모델 호출0회다.
- 실제50개 reader 출력을 같은 입력으로 재생했고 질의 생성10회, 원래 top8의10문항 재현, 원문 구절89개 위치와 source/config/입력 해시를 확인했다. 관련 테스트35개와 실제 HTTP 전송1개가 통과했다. [검증 기록](verification.json) · [테스트](tests.log) · [전송 검사](transport-tests.log)

```sh
NLTK_DATA=.cache/reference-nltk TOKENIZERS_PARALLELISM=false \
  .venv/bin/python -m evaluation.reference_qa.contextual.verify
.venv/bin/python -m evaluation.reference_qa.contextual.report prepare
.venv/bin/python -m evaluation.reference_qa.contextual.report score
```

이 명령은 저장된 실제 출력과 명시적인 판정을 검사하며 모델을 다시 호출하지 않는다. 의미 평가는 구현 담당 AI가 원문을 읽어 수행했다. 이미 본 작은 개발셋이며 독립 사람 채점·전체 벤치마크·승인·병합 평가는 포함하지 않는다.

## 설계 판단

원문 맥락을 보존하는 연결은 업로드 사례에서 효과를 확인했다. 명시적인 배정 기록을 찾는 검색도 담당자 사례를 복구했다. 그러나 질의 확장이 잘못된 인물과 일반 규칙에 머물고, 선택 단계가 핵심 완료 구절과 출력 계약을 놓쳤다. 이번 결합을 완성된 개선안으로 채택하지 않는다. `contextual`은 재현 가능한 실험용 프로필로 남기고 `attributed`를 유지한다. 고정 비교 이후 새 모델 실험은 추가하지 않았다.
