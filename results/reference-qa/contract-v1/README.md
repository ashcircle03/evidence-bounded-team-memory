# 상태와 입출력 계약 수정

- 인용 JSON 실패·인용 미완료는 `partial`과 `stage_failures`로 반환한다.
- AQA 보정이 수락돼도 이전 미완료 상태와 경고는 유지한다.
- 원형 ConflictScore 예외 메시지를 stderr logging으로 옮겼다. CLI 전체 초기화·처리 경계도 JSON 응답 stdout과 분리했다.
- 별도 모델 객체 설정으로 실제 문서 판정 HTTP 요청을384토큰으로 제한한다. 답변 생성 객체1024 설정은 유지한다.

`tests.log`:253개 로컬 테스트 통과. 실제 LlamaIndex의 검색→선택→주장 생성 연결은 가짜 디코더로 검사했다. 모델 의미 성능은 이 테스트의 대상이 아니다.

`replay.json`: 기존20개 초안20호출 확인 + 후속112호출의 실제 메시지 일치 재생. 답과 근거는20/20 동일. 잘못된 인용 JSON4개·남은 미인용 문장4개가 기존ok에서partial로 바뀐다. 미인용 문장이 모두 사실 문장이라는 의미는 아니며, 상태는 인용 처리의 완료 여부다. 이전 원출력·점수 파일은 수정하지 않았다.

재생은 저장된 모델 응답을 사용한다. 수정된384토큰 제한으로 새 추론을 한 결과가 아니며, 검색도 다시 실행하지 않았다. 새 claims 경로와 확대 평가의 Qwen 결과는 별도 `claims-v2`에 기록한다.
