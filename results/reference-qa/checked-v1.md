# 이전 checked19/20 결과와 당시 채택 판단

**같은 개발20문항의 고정 기준에서15/20 → 19/20, 기존 성공15개를 모두 유지했다. 요청한 남은5건 중4건을 복구했고1건은 해결하지 못했다.** 현재 사용할 구성은 `--profile checked`다. 마지막 상충1건을 복구한 별도 대안은 일반 질문2건을 망쳐18/20으로 내려갔으므로 채택하지 않았다.

점수는 **필수 답·조건이 맞고 그 답의 인용 원문이 지지하는지**에 대한 기존 기준이다. 모든 부연 문장의 인용 완전성을 뜻하지 않는다. 선택안의 PEP618·PEP680 답에는 실제 입력에 존재하는 부연을 별도 인용 없이 추가한 문제가2건 남아 있다. 이2건까지 실패로 보는 보수적인 추가 집계는17/20이다. 독립 평가나 ALCE AutoAIS를 실행한 결과는 아니다.

## 마지막 대안을 기각한 이유

공식 LlamaIndex `Accumulate`는 각 문서를 독립적으로 읽고 답을 나란히 반환한다. 한쪽을 버리는 합성 단계를 피할 수 있을 것으로 보고, 반대 판정 원문이 인용에서 누락된3문항에 같은 조건으로 적용했다. 문서 판정의 오탐을 신뢰한 것이 문제였다.

- strict zip에서는 Fay의 LengthMismatchError와 PEP618의 ValueError를 모두 보존했다.
- notes.mergeStrategy에서는 정답 manual 외에 format.notes의 false와 notes.rewriteMode의 concatenate를 같은 질문의 답으로 잘못 추가했다.
- Confluence에서는 다른 작성자의 프로젝트 charter 경로를 Huilan Chen의 분석 보고서 위치에 대한 답으로 잘못 추가했다.

각 문서의 답을 따로 만들면 무관한 문서에서도 답을 억지로 만들 수 있다는 실제 결과다. 단순히 모든 답을 나열하는 방식은 채택하지 않았다. 현재 `ConflictCheckedQA`는 이 대안을 호출하지 않으며, 재현용 함수와 실패 결과만 보존했다. [기각안 원출력과 판정](accumulate-v1/comparison.md)

선택한19/20 구성에도 notes.mergeStrategy·Confluence·Lizhen Zhou의 문서 판정 오탐3건으로 불필요한 재작성이 있었다. **최종 QA 정답 유지와 내부 판정 정확도는 다르다.** 마지막 실패를 고치려면 실제로 같은 질문·대상·동작에 관한 반대 근거인지 확인하는 능력과, 확인된 근거를 답에서 누락하지 않는 능력이 함께 필요하다. 새 규칙을 더 붙이면 해결된다고 결론내리지 않는다.

## 실제 실행과 검증 범위

모델은 모두 같은 로컬 Qwen3-8B 비사고 모드다. 입력은 동일한 전체 기록과20문항이며, 정답 키를 모델에 보내지 않았다. 이20개는 이미 본 개발 문항이고 자연 EverMemBench 질문은3개뿐이다. 다른 조건의 공존과 상충 기록은 통제 구성이다. 전체 벤치마크 성능이나 새 Git 재검토·승인 의미의 개선을 주장하지 않는다.

- 전체 실행119872: 실제114호출(초안20·문서 판정89·재작성5). Slurm COMPLETED/0:0. 답·근거19/20이었지만23개 판정 출력의 JSON 파싱이 실패했다.
- 파서 복구119928: 저자 코드의 명시적인 answer/support/XML 표기 복구를 적용했다.20문항을 고정 재생하며 기존114호출을 재사용하고, 새로 도달한 zip 재작성1회만 실행했다.23개 판정을 복구했지만 답 점수는19/20이다. 다른19개 답의 원문 문자열은 같았다.
- Accumulate119944: 앞선115호출과20개 출력을 고정하고 일반 조건으로 선택된3문항에 문서별 QA 8회를 추가했다. 나머지17개 답은 동일하다. Slurm COMPLETED/0:0, 총123개 실제 호출의 출처 연결을 검증했다.18/20이므로 기각했다.
- 매번20문항 전체를 새로 추론한 실험으로 표시하지 않는다. 각 단계의 코드·입력·이전 결과를 실행 전 고정하고 호출별 실제 입력·원출력, 인용 원문과 문자 위치를 검증했다. Accumulate 출력은 하나의 모델 원출력이 아니라 실제 원출력들을 upstream 규칙으로 붙인 결과라고 별도 표시했다.
- 현재 선택한 클래스는119928 코드와 AST가 같고, QA·프롬프트 파일도 동일하다. 전체 로컬 검사234개와 원복 후 연결 검사11개를 통과했다. 가짜 디코더를 사용하는 검사는 의미 성능의 증거와 구분한다.

개발 담당 AI가 원문을 대조해 판정했다. 독립된 사람의 채점은 없다. 검색·작성자 전달·문서 검토가 함께 바뀌었으므로 개선 원인을 단일 요소의 인과 효과로 해석하지 않는다. ALCE 형태의 출력은 있지만 Source N 표기 정규화와 AutoAIS 실행은 하지 않았다.
