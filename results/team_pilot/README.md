# 팀 지식 파일럿 · 입력 검증

모델 실행 전에 동결한 104개 입력을 새 체크아웃에서 다시 생성해 모든 프롬프트와 패킷의 해시가 일치하는지 확인했다. 다음 수치는 Qwen이 보기 전의 검색 결과를 측정한다. [평가 계획과 재현](../../evaluation/team_pilot/README.md) · [104개 입력 해시](../../evaluation/team_pilot/freeze.json)

| 모델에 실제로 전달되는 내용 | 단순 검색 | 후보 모듈 |
|---|---:|---:|
| 일반 QA에서 원본 문서와 정답 문자열이 같이 있음 | 9/10 | 9/10 |
| 무관한 일정 충돌 추가 후에도 원문·정답 문자열이 같이 있음 | 9/10 | 9/10 |
| 반사실적 보고 추가 후 두 답이 각각 지정한 출처에 있음 | 9/10 | 9/10 |
| 재검토 양성에서 과거 결정의 이유와 새 근거의 등록 구절이 모두 있음 | 10/10 | 10/10 |

두 방식의 일반 QA에서 모두 빠진 것은 PEP 552의 해시 알고리즘 이름이다. 이 문항은 정답을 원문에서 복사하는 현재 경로로 통과할 수 없다. 다른 문항의 문자열이 입력에 있어도 모델이 적절한 답과 근거를 고르는지는 별도 평가 대상이다. [문항별 검색 결과](input-coverage.json) · [입력 검사 코드](../../evaluation/team_pilot/coverage.py)
