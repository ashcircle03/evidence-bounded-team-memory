# 버전 외 도메인 전이 평가

사전 고정된 합성 3개 도메인·6문항. 각 도메인은 같은 질문·조건·첫 기록을 유지하고 다른 기록의 결과만 바꾼 대응쌍이다. Qwen3-8B와 124347의 제품 코드 아카이브, 원문/메타데이터, 디코딩, 출력 예산을 공유한다. gold는 추론에 전송하지 않는다. 두 방식 모두 실제 공식 포트와 동일한 원문 인용 검증기를 쓰고 한 번 생성한다. 단순 방식은 답과 인용 및 outcome을 바로 반환한다. 후보는 비교 설명과 same_answer를 함께 생성한다. 도메인 데이터 수집이나 검색 성능은 범위 밖이다.

문항 통과 조건은 이전 네 문항과 같다. 두 조건의 핵심 결론이 질문을 의미상 정확히 답하고 각 조건이 올바른 evidence_id에 연결되며 각 인용이 해당 결론을 지지해야 한다. 질문에 대해 같은 결론이면 answered, 다르면 conditional이어야 한다. 핵심 답을 뒤집는 부연, 빠진 조건, 미지원 주장, partial/error는 실패다. 표현·단위 차이는 gold와 의미가 같으면 인정한다. 응답의 진단 설명과 주장 내용이 모순되면 별도로 기록한다. outcome, 의미상 정답, 모든 조건/근거 보존, 전체 공동 통과를 따로 센다. 같은 근거에서 파생한 문항끼리는 독립 표본으로 해석하지 않는다.

채택 판단: 두 도메인 이상에서 공동 통과를 새로 얻고 단순 방식이 맞힌 문항을 잃지 않으면 후보의 추가 비교 지시를 유지한다. 양쪽 모두 같은 문항을 통과하면 단순 방식을 우선한다. 퇴행이나 한 도메인에만 집중된 이득은 보류한다. 역방향으로 같은 개선 기준을 만족하면 단순 방식을 우선한다. 추가 토큰과 모델 호출 수도 보고한다. 이전 버전 사례는 점수에 합산하지 않는다. 이 패널에는 재시도·설계 수정 후 재채점하지 않는다.
