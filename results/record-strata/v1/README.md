## 해석 한계

- 자연 원문은 실패를 보고 고른 사례이고 정답도 초점 부분만 지정했다. 전체 추출 정밀도/재현율이나 EverMem 공식 점수가 아니다.
- 같은8B의 두 프롬프트가 모두 틀려도 모델의 본질적 능력 한계로 확정할 수 없다. 공통 출력 계약의 영향이 남는다.
- 내용 회수는 조건이 claim에 포함된 경우도 센다. 역할 완비는 뒤 모듈이 별도 조건·이유 필드로 접근 가능한지를 센다.
- 저장 전달은 새 adapter 인스턴스와 reader packet을 검사한다. 새 OS 프로세스 재시작이나 최종 QA 추론은 이번 실행 범위가 아니다.
- 생산 코드는 변경하지 않았다. 기존QA20 결과를 이번에 새로 실행한 것처럼 합산하지 않는다.
